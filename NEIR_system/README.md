网络设备信息记录系统

项目简介

这是一个基于 Python 开发的轻量级工具，主要用于管理局域网内的硬件设备信息，并能实时检测设备的在线状态。

1.核心功能
信息管理： 支持设备名称、IP 地址、型号、位置等信息的增删改查（CRUD）。

自动检测： 录入信息时自动触发 Ping 检测，判定设备是否在线。

一键刷新： 点击 Refresh 即可对数据库中所有已保存设备进行批量状态扫描。

局域网扫描： 自动识别本地网段并扫描在线 IP，支持一键入库。

2.运行与保存
运行环境： Python 3.x（无需安装第三方库）。

启动方式： 直接运行 python main.py。

数据保存： 数据保存在项目根目录下的 device.db (SQLite3 数据库) 中。
